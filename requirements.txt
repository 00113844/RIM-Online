# currently builds on 3.14. Keep the floors low enough that both resolve.

# ── Cold-rebuild marker ──────────────────────────────────────────────────────
# Streamlit Cloud warm-restarts on a new commit: it re-executes page files but
# keeps already-imported modules in sys.modules. A deploy that changes a page
# and a utils/ module together then runs the NEW page against the OLD module.
# That has now broken three deploys, in two ways:
#
#   ImportError: cannot import name 'FIELD_HELP' from 'utils.year_editor'
#   TypeError:   save_load_controls() takes 1 positional argument but 2 given
#
# A missing name can be dodged by putting shared things in a new module, which
# cannot have been cached. A changed *signature* cannot: the old function is
# simply the wrong shape, wherever it lives.
#
# Changing this file invalidates the environment and forces a cold rebuild, so
# every module is imported from disk. **Bump the marker below in the same commit
# as any change to a function signature, or to a name a page imports, under
# utils/ or rim/.** See .claude/memory/streamlit-widget-state-staleness.md.
#
